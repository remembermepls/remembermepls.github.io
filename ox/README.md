# OX 서바이벌 퀴즈

- 참가자 페이지: `/ox/`. 이름을 입력해 입장하고, 맞히면 다음 문제로 넘어가고 틀리면 탈락해요.
- 관리자 페이지: `/ox/admin.html`. 문제를 등록하고 출제, 마감, 채점을 진행해요.

## Firebase 설정 (처음 한 번)

1. https://console.firebase.google.com 에서 **프로젝트 추가**를 누릅니다. 애널리틱스는 꺼도 돼요.
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**를 누릅니다.
   - 위치는 `asia-southeast1 (싱가포르)`를 추천해요.
   - 보안 규칙은 아무거나 고르고 넘어간 뒤, 다음 단계에서 바꿉니다.
3. Realtime Database의 **규칙** 탭에 `ox/database.rules.json` 내용을 그대로 붙여 넣고 **게시**를 누릅니다.
4. **프로젝트 설정(톱니바퀴) → 일반 → 내 앱 → 웹(`</>`)**에서 앱을 등록합니다. 그러면 `firebaseConfig` 값이 나와요.
5. 그 값을 `ox/firebase-config.js`에 붙여 넣습니다.
   - `databaseURL`이 없으면 Realtime Database 화면 위쪽에 있는 주소를 넣으세요.

## 진행 순서

1. 관리자 페이지에 비밀번호를 입력해 들어가서 문제를 등록해요. 한 번에 여러 개 등록할 수도 있어요.
2. 참가 주소를 공유하면 참가자들이 이름을 입력하고 입장해요. 같은 이름은 쓸 수 없어요.
3. **출제**를 누르면 생존자 화면에 문제가 뜨고, 이때부터 새로 입장할 수 없어요.
4. 제한시간이 끝나면 자동으로 마감돼요. **정답 공개 · 채점**을 누르면 틀렸거나 답을 내지 않은 사람이 탈락해요.
5. 다음 문제를 출제하는 식으로 반복하고, 끝나면 **게임 종료 · 우승 발표**를 누릅니다.

- 전원이 탈락했을 때는 **이번 탈락자 부활**로 방금 라운드에서 떨어진 사람들을 살릴 수 있어요.
- 참가자가 새로고침해도 같은 기기라면 그대로 이어서 참여해요.

## 알아 둘 점

- 로그인 없이 동작하는 간단한 구조예요. 브라우저 개발자 도구를 다룰 줄 아는 사람이라면 데이터를 조작할 수 있어요. 행사용으로 쓰기에는 충분하지만, 상금이 걸린 대회라면 Firebase Authentication을 추가하는 게 좋아요.
- 문제와 정답은 관리자 비밀번호를 알아야 찾을 수 있는 위치에 저장돼요. 정답은 채점할 때만 참가자에게 공개돼요.
- 무료 요금제(Spark)는 동시 접속 100명까지라서 50명은 충분해요.
