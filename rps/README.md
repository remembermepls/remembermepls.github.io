# 가위바위보 서바이벌

- 참가자 페이지: `/rps/`. 이름을 입력해 입장하고, 관리자와 가위바위보를 해요.
- 관리자 페이지: `/rps/admin.html`. 라운드를 열고, 마감하고, 관리자의 손을 공개해 채점해요.

규칙은 간단해요. **관리자를 이기거나 비기면 생존, 지거나 아무것도 내지 않으면 탈락**이에요.

## Firebase 설정

OX 서바이벌(`/ox/`)과 같은 Firebase 프로젝트를 써요. 설정값은 `ox/firebase-config.js`에서 그대로 가져오고, 데이터만 `rps/` 아래에 따로 저장해요.

한 가지만 해 주세요. Firebase 콘솔 → Realtime Database → **규칙** 탭에 저장소 맨 위의 `database.rules.json` 내용을 붙여 넣고 **게시**를 누르세요. OX 규칙도 함께 들어 있어서 OX 퀴즈는 그대로 동작해요. 이걸 안 하면 가위바위보 페이지에서 저장이 거부돼요.

## 진행 순서

1. 관리자 페이지에 비밀번호를 입력해 들어가요. 처음이면 새로 정할 비밀번호를 입력하면 돼요.
2. 참가 주소를 공유하면 참가자들이 이름을 입력하고 입장해요. 같은 이름은 쓸 수 없어요.
3. **다음 라운드 준비**에서 관리자가 낼 손(가위 · 바위 · 보 · 랜덤)과 제한시간을 고르고 **라운드 시작**을 눌러요.
   - 손은 시작하는 순간 정해지고 참가자는 볼 수 없는 곳에 저장돼요. 시작한 뒤에는 바꿀 수 없어요.
   - 첫 라운드를 시작하면 입장이 자동으로 잠겨요.
4. 생존자들이 가위 · 바위 · 보 중 하나를 골라요. 마감 전까지는 바꿀 수 있어요. 관리자 화면에서는 누가 무엇을 냈는지, 몇 명이 탈락할지 실시간으로 보여요.
5. 제한시간이 끝나면 자동으로 마감돼요. **손 공개 · 채점**을 누르면 모두의 화면에 관리자의 손과 결과가 떠요.
6. 다음 라운드를 시작하는 식으로 반복하고, 끝나면 **게임 종료 · 우승 발표**를 눌러요.

- 전원이 탈락했을 때는 **이번 탈락자 부활**로 방금 라운드에서 떨어진 사람들을 살릴 수 있어요.
- 참가자가 새로고침해도 같은 기기라면 그대로 이어서 참여해요.
- 관리자 페이지를 다른 기기에서 열 때는 같은 비밀번호로 들어가야 진행 중인 라운드의 손을 찾을 수 있어요.

## 알아 둘 점

- 로그인 없이 동작하는 간단한 구조라서, 브라우저 개발자 도구를 다룰 줄 아는 사람이라면 데이터를 조작할 수 있어요. 행사용으로는 충분하지만 상금이 걸린 대회라면 Firebase Authentication을 추가하는 게 좋아요.
- 관리자의 손은 비밀번호 해시로 만든 주소에 저장되고, `game`에는 공개할 때 처음 적혀요.
